Final Project Proposal

An interactive website based around one window pane and three seasonal environments.

Window Pane Concept

My final website will have a home page and three connected pages. Each page will show the same window pane, but the environment outside the window will change according to each season (Spring, Summer, Fall).

Current scene: Summer Fireflies

Theme

My final website will be about looking through one window at different seasonal environments. The window stays the same, but the scene outside changes through color, movement, and overall atmosphere.

Website Description

The final website will have one home page and three idea pages: spring petals, summer fireflies, and autumn leaves. Each page will use the same window pane structure, but the visual mood will change. The spring page will show falling petals, the summer page will show glowing fireflies, and the autumn page will show drifting leaves. I chose to not incorporate winter, as the final project is limited to three pages—I felt that spring, summer, and autumn had the potential to be visually distinct.

Page Plan

The home page will introduce the overall window concept. The spring page will focus on soft petals and lighter colors. The summer page will focus on a darker nighttime scene with fireflies. The autumn page will use warmer colors and animated leaves.

Fonts

I want to use clean and readable fonts. For the headings, I may use a softer or slightly rounded font to match the calm and visual feeling of the website. For body text, I will use a simple sans-serif font. Like my midterm project, I am considering using a different font for each season/page.

Colors

The colors will change depending on the seasonal page. Spring may use soft pinks and pale greens, summer may use blues and yellows, and autumn may use oranges and browns. The overall site will stay simple so the window scenes can stand out.

JavaScript Element

The JavaScript element will help make the website interactive. The user may be able to click or move the mouse to affect the movement of petals, fireflies, or leaves. Each page may have a small interactive detail connected to its season.

p5 Element

Each seasonal page will include a p5.js sketch. The spring sketch may show petals falling, the summer sketch may show fireflies glowing and moving, and the autumn sketch may show leaves drifting across the window. I want the p5 sketch to be the main visual element of each page. I've included a p5.js sketch of the fifreflies from a previous assignent.

jQuery Element

I will use jQuery to reveal and hide sections with slideToggle(). I will also use jQuery to change the sample window scene by updating the background, particles, and text. This connects to the class examples because jQuery can be used for events, effects, CSS changes, and DOM manipulation.

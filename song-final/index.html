Through the Window

An interactive seasonal website centered around one window pane.

Home Spring Summer Autumn Winter

Project Concept

This website explores the feeling of looking through the same window across four different seasons. Each page will keep the same window structure, but the colors, movement, and atmosphere will change for visual distinction.

Spring

Falling petals outside the window.

Summer

Fireflies glowing at night.

Autumn

Leaves drifting through the air.

Winter

Snow falling outside.

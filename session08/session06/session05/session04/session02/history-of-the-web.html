History of the Web

1989-1990, World Wide Web (WWW), Tim Berners-Lee and Robert Cailliau

The World Wide Web (WWW) was invented by Tim Berners-Lee in 1989 (the first proposal), during his time at CERN. Robert Cailliau joined WWW The Project in 1990 to help with a rewritten version of the proposal. Together, HTTP (HyperText Transfer Protocol), HTML (HyperText Markup Language), and URLs (Uniform Resource Location) were defined as the core technologies for the World Wide Web.
